# A small poetry shelf for future readers

These are original pieces for the people who inherit a repository after the
exciting part. Read them in any order. The cache does not care.

## Haiku: rootfs

Bytes wait in the dark  
One path, one hash, one question  
Is it here at runtime?

## Limerick: the cache

There once was a cache made of hash,  
That refused to duplicate a stash.  
It kept paths out of sight,  
Linked results just right,  
And vanished when done with the bash.

## Sonnet-ish: Orthogonality

Let image tools resolve what they can see,  
Let scanners ask the bytes what they contain,  
Let VEX describe what runtime claims may be,  
And let comparison name the weather vane.  

No registry should dictate a scan,  
No report should rebuild a hidden fact,  
No status should pretend its model can  
Replace the evidence that made the act.  

When syntax meets semantics, be kind:  
The difference is a map, not merely blame.  
Precision gives the future mind  
A sharper place to improve the frame.

## Villanelle: The file was not found

The file was not found; do not declare it gone.  
A missing path is not a whiteout’s voice.  
The layers keep their secrets one by one.

Perhaps a later layer carried on.  
Perhaps an opaque directory made the choice.  
The file was not found; do not declare it gone.

The report may say “unknown” and move along;  
That modest word can preserve a choice.  
The layers keep their secrets one by one.

If evidence says “replaced,” pass it on.  
If deletion is proved, state it without noise.  
The file was not found; do not declare it gone.

And if no explanation appears before dawn,  
Call it unaccounted — strange? — and rejoice:  
The layers keep their secrets one by one.

## Free verse: VEX and pygo

One says:

> the product is affected.

The other says:

> I searched the supplied bytes and found no compiled code for that claim.

Neither sentence should be thrown away.

Put them on the same table.
Give the disagreement a name.
Ask whether they are discussing
the same digest,
the same component,
the same runtime,
the same idea of “present.”

Sometimes they disagree.
Sometimes they agree in different dialects.
Sometimes they achieve
the rare and beautiful state
of violent agreement.

## Ballad of the little hat

A smell came down the code review lane,  
With a tiny hat to shade the rain.  
“I’m not a bug,” it said, “not yet,”  
“But I am a thing you might regret.”

The model had facts; the view had none,  
So every renderer fetched them one by one.  
The hat tipped left. The tests turned blue.  
The fact moved up where the model knew.

## Ode to the host tool

O `go`, read the metadata and leave the binary sleeping.  
O `govulncheck`, bring your database and your reachability reasoning.  
We will not execute the stranger in the rootfs.  
We will ask questions, write them down, and keep the receipt.

## Closing couplet

Keep dependencies few, keep conclusions clear;  
Leave better evidence for whoever works here.
